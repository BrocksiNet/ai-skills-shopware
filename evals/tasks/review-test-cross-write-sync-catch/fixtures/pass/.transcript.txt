The test updates the media entity with private=true in one call, then updates it again with fileExtension=zip in a separate PUT call. The validator that checks for MEDIA_ILLEGAL_FILE_EXTENSION will only see the fileExtension when it validates that second write, not the merged state where both private and fileExtension are set together. This should be tested through /api/_action/sync with both writes in one Sync request.

# sw-mcp-development — should NOT trigger

- How do I configure Claude Desktop or Cursor to connect to my shop's /api/_mcp endpoint? (runtime setup, out of scope)
- Does my MCP tool need #[McpToolRequires] or requirePrivilegeResult() to block unauthorized users? (-> sw-security)
- Add a Store API controller route with OpenAPI schema for my plugin. (-> sw-plugin-development)
- Generate a request and response DTO from an OpenAPI schema with x-dto-namespace. (-> sw-openapi-dto)
- Write a PHPUnit unit test for my plugin's cart processor. (-> sw-testing)
- Add a webhook and permissions to my Shopware app manifest.xml. (-> sw-app-development)
- Run bin/console cache:clear in my DDEV local environment. (-> sw-local-dev)

### 1. What and why?

- CartProcessor cannot be decorated by plugins today; plugins can only replace it.

### 2. How?

- Add `AbstractCartProcessor` and make `CartProcessor` extend it, so plugins decorate the abstract type.

#### Impact

- New abstract class `AbstractCartProcessor`. Plugins decorate it instead of the concrete class:

```php
class MyCartProcessor extends AbstractCartProcessor
{
    public function __construct(private readonly AbstractCartProcessor $inner) {}

    public function getDecorated(): CartProcessorInterface
    {
        return $this->inner->getDecorated();
    }
}
```

### 3. Testing

1. Register a decorator for `AbstractCartProcessor` in a test plugin.
2. Run a cart calculation and check that the decorator runs.

### 4. Additional notes

- Follow-up: move the existing decorators in core to the abstract class.
